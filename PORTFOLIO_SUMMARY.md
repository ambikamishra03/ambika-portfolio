## 🚀 Quick Start Summary

### Step 1: Extract
```bash
unzip ambika-portfolio.zip
cd ambika-portfolio
```

### Step 2: Backend
```bash
cd backend
npm install
# Set up .env with MongoDB URI
npm run dev
```

### Step 3: Frontend (New Terminal)
```bash
cd frontend
npm install
npm run dev
```

### Step 4: Open
Visit **http://localhost:3000** in your browser 🎉
